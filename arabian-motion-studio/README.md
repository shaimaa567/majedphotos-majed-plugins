# Arabian Motion Studio · استوديو Ms. Memories

استوديو إبداعي لصناعة محتوى **Ms. Memories** (كتب الذكريات، طباعة الصور، دعوات المناسبات والدعوات الإلكترونية): واجهة ويب بالعربية فوق محرك فيديو حقيقي (Chromium + SVG/CSS + ffmpeg) يصدّر **MP4 عمودي 9:16**.

## تشغيل الاستوديو

```bash
npm install
npm run studio          # ثم افتحي http://127.0.0.1:4173
```
يتطلب: Node ≥ 20.12 و`ffmpeg` وChromium (Playwright). الخادم يعمل على جهازك فقط (127.0.0.1).

| | |
|---|---|

| معاينة حية | نفس المحرك المستخدم في التصدير، فما تراه هو ما يُصدَّر. تشغيل، وسحب شريط الزمن، والقفز لمشهد |

### عناصر هوية Ms. Memories في المحرك
`polaroid` إطار Polaroid بشريط لاصق وتعليق بخط الرقعة · `ribbon` شريط ساتان أحمر · `bow` فيونكة · `rays` أشعة الضوء · `sparkles` لمسات سحرية · خلفيات `lattice` و`frames` · خطوط: كوفي، تجوال، الرقعة، المسيري.
الألوان في المشاريع بأسماء الباليت (`accent`، `ink`…) فتغيير ألوان المشروع يعيد تلوين كل شيء.

## المرحلة 2: من الفكرة إلى مخطط مشاهد مخصص

اكتبي فكرة الإعلان بالعربية في الصفحة الرئيسية ← **حلّلي الفكرة وأنشئي المخطط**. المخطِّط (محلي، بلا خدمات خارجية) يعمل هكذا:

1. **تحليل الفكرة:** المنتج (كتاب ذكريات، ألبوم، طباعة صور، دعوات، دعوة إلكترونية…)، المناسبة (زفاف، تخرج، أم، مولود…)، العرض (خصم %، سعر، مدة)، المزايا المذكورة (توصيل، تغليف، غلاف…)، النبرة، ونوع الدعوة للإجراء (رابط البايو، واتساب…) وعبارات «بين علامتي اقتباس» تُستعمل كما هي.
2. **قصة المشاهد:** تسلسل يناسب النوع والمدة (6–8 مشاهد للريل): افتتاح ← لحظة عاطفية ← كشف المنتج ← مزايا ← خطوات/مناسبات ← عرض (إن ذُكر) ← دعوة للإجراء.
3. **نصوص عربية مفصَّلة على الفكرة** (لا قالب بنص مبدّل): صياغات متعددة تُختار بـ seed، مع مخاطبة مؤنث/مذكر، ولا تُخترع أسعار أو مزايا لم تذكريها.
4. **18 تكوينًا بصريًا** (Polaroid كبير، ثلاث صور، كتاب مفتوح، كتاب على الأحمر، قطع قطري، قائمة بأيقونات، كلمة ضخمة، رقم العرض، فيونكة الختام…). المحدِّد لا يكرّر تكوينًا، ويبدّل بين الأبيض الحليبي والأحمر، ويغيّر حركة الكلمات والانتقالات وجهة الأشعة والإطارات، ويختار عناصر الهوية بحسب الفكرة بدل وضعها كلها في كل مشهد.
5. **صور المنتج:** صورك المرفوعة تُستخدم أولًا (لا تتكرر). وإلا يُرسم بدلها تصميم أصلي بأسلوب البراند (كتاب، مطبوعات، بطاقة دعوة، رسوم داخل Polaroid) — وهي **ليست صورًا مولّدة**.
6. **اقتراحات الصوت:** نص تعليق صوتي مقسّم على المشاهد بزمن تقريبي، موسيقى مقترحة، ومؤثرات مرتبطة بأزمنة الانتقالات والعناصر. (نص اقتراحي؛ لا يُولَّد صوت).

بعد التوليد: تبويب **الخطة** يعرض ما فُهم من الفكرة، ومخطط المشاهد (ولماذا اخترنا كل تكوين)، والصور المطلوبة بوصفها، والصوت المقترح. من تبويب **المشهد**: «🎲 مشهد جديد» / «نص جديد فقط» / «تكوين جديد فقط» لإعادة توليد **مشهد واحد دون المساس بالباقي**، و«إضافة مشهد ذكي» بدور محدد، إضافة إلى النسخ والحذف والترتيب والتراجع (Ctrl+Z).

### الصور بالذكاء الاصطناعي (بنية جاهزة، بلا خدمة مربوطة)
زر «✨ توليد بالذكاء الاصطناعي» يرفض بوضوح الآن لأنه لا توجد خدمة مربوطة. لإضافة خدمة لاحقًا: انسخي `studio/imagegen/providers/_template.mjs` إلى `<name>.mjs`، واكتبي استدعاء الـ API، وضعي مفتاحها في `.env`. تُكتشف تلقائيًا، وتُحفظ الصورة الناتجة كأصل مسجَّل (`source: ai-generated`) وتُسند للمكان المطلوب. لا تُعلَن الخدمة «مختبرة» حتى تضبطي `tested: true` بعد تجربتها فعليًا. كل مكان صورة يحمل وصفًا بالعربية والإنجليزية جاهزًا للنسخ إلى أي أداة.

### صياغة النصوص بـ Claude (اختياري)
إن وُضع `ANTHROPIC_API_KEY` في `.env` يظهر خيار «صياغة النصوص بـ Claude» (SDK الرسمي، `claude-opus-5-5`، مخرجات منظَّمة). يعيد كتابة النصوص والتعليق فقط، أما التكوين والتوقيت والتحقق فمحلية، وإن فشل الاستدعاء أو رُفض الرد يُستخدم المخطِّط المحلي مع تنبيه. **هذا المسار لم يُجرَّب على الـ API الحقيقي** (لا مفتاح في التطوير)؛ اختُبر بناء الطلب والتحقق من الرد بعميل وهمي فقط.

## المحرك والأوامر (CLI)

أداة تنتج فيديوهات قصيرة عمودية **9:16 (1080×1920)** بنصوص عربية RTL ورسوم رقمية حادة وأيقونات Lucide وصور/مقاطع Pexels، وتصدّرها كملف **MP4 حقيقي** (H.264 + AAC).

## كيف تعمل (التقنية)

```
project.json (مشاهد كبيانات)  ──►  engine/runtime.js  (SVG + CSS + DOM، دالة في الزمن t)
                                     │  Chromium بلا واجهة (Playwright) يلتقط إطارًا لكل t
                                     ▼
                                   ffmpeg: ترميز H.264 + مزج الصوت + ضبط الجهارة −14 LUFS
```

- **لماذا DOM/SVG؟** المتصفح يشكّل الحروف العربية ويدعم RTL والـ bidi بشكل صحيح؛ أفضل من Canvas.
- **حتمي:** نفس `t` = نفس الصورة دائمًا، فالمعاينة تطابق التصدير.
- الخطوط: Tajawal وNoto Kufi Arabic (OFL) بأوزانها الحقيقية في `assets/fonts/`.

## التشغيل

```bash
npm install
node src/cli.mjs check demo                       # فحص المشروع
node src/cli.mjs sheet demo --from 0 --to 4       # لوحة معاينة (صورة واحدة بكل الحركة)
node src/cli.mjs render demo --preview            # معاينة منخفضة الدقة
node src/cli.mjs render demo                      # تصدير نهائي → output/demo/demo_v1.mp4
```

يتطلب: Node ≥ 20.12، `ffmpeg`/`ffprobe`، وChromium (مع Playwright؛ إن لم يكن مثبتًا: `npx playwright install chromium` أو اضبط `CHROME_PATH`).

## بنية المشروع

```

projects/<name>/

  assets.json      سجل الصور/المقاطع (المصدر، المصوّر، الرخصة، أين تُستخدم)

```

مشروع جديد: `node src/cli.mjs new my-reel`.

## أنواع الطبقات في المشهد

| type | الاستخدام |
|---|---|
| `art` | رسم رقمي حاد مولّد بـ seed: `style` = `shards` `lines` `rings` `bands` `grid` |
| `bgtext` | نص ضخم في الخلفية (إطار فقط) يتحرك ببطء، صفوف بعكس الاتجاه |
| `text` | نص عربي RTL، كشف كلمة كلمة. `*كلمة*` = إبراز. الكلمات اللاتينية تُعزل تلقائيًا (LTR) |
| `icon` | أيقونة Lucide بالاسم `"name":"rocket"` مع رسم الخط `in:"draw"` وإطار `badge` |
| `image` | صورة من `assets.json`: `clip` (قصّ مضلّع حاد)، `kenburns`، `filter`، `overlay` |
| `video` | مقطع من `assets.json` (`trim` = ثواني البداية داخل المقطع) |
| `shape` | مستطيل/مضلّع حاد |

حركات الدخول `in`: `fade rise drop slideR slideL scale pop wipe wipeUp blur draw` — والخروج `out` + `outAt`.
`slideR` و`wipe` يتقدمان من اليمين لليسار (اتجاه القراءة العربي).

انتقالات المشهد `transitionIn`: `wipe` (قطع قطري) · `bars` (قضبان) · `slide` · `fade`.

## الصور والأيقونات (تغييرها سهل)

- **أيقونة:** غيّر `"name"` فقط. البحث: `node src/cli.mjs icons search video`.
- **صورة من Pexels:**
  ```bash
  node src/cli.mjs pexels search demo --q "كاميرا سينمائية" --type photo     # قد يلزم بالإنجليزية: "cinema camera"
  # راجع الصور المصغرة في projects/demo/.cache/candidates/ ثم:
  node src/cli.mjs pexels pick demo --id 1234567 --as hero_s2 --scene s2
  ```
  ثم أضف طبقة `{"type":"image","asset":"hero_s2", ...}` في المشهد. لتغييرها لاحقًا: غيّر `asset` أو اختر غيرها.
- **تجنب التكرار:** `check` يفشل إذا تكرر أصل أو رقم Pexels أو ملف مطابق أو أيقونة أو (style+seed) أو نص بين المشاهد، و`pick` يرفض اختيار نفس المقطع مرتين.

## مفاتيح API (بأمان)

1. أنشئ مفتاح Pexels المجاني من https://www.pexels.com/api/
2. `cp .env.example .env` ثم الصق المفتاح بعد `PEXELS_API_KEY=` واحفظ.
3. الملف `.env` مستثنى من git؛ لا تلصق المفتاح في المحادثة ولا في أي ملف آخر.

بدون مفتاح تعمل كل الميزات الأخرى (الرسم الرقمي، الأيقونات، الصور/المقاطع التي تضعها بنفسك).

## الصوت والتعليق الصوتي والمزامنة

في `project.json`:
```json
"sync": "sync.json",
"audio": { "vo": "audio/vo.mp3", "music": "audio/music.mp3", "musicGain": -18,
           "sfx": [ { "file": "audio/whoosh.wav", "at": "@scene:s2", "gain": -8 } ] }
```
1. اكتب سكربت التعليق، ولّده بصوت من اختيارك، وضع الملف في `audio/`.
2. `pip install faster-whisper` ثم `node src/cli.mjs sync <project>` ← يكتب `sync.json` بزمن كل كلمة. قارن النص بالسكربت وصحّح.
3. اربط العناصر بالكلام: `"at": "@w12"` (بداية الكلمة 12) · `"@w12.e"` (نهايتها) · `"@w12+0.2"` · `"@scene:s3"` · نص كامل: `"wordsFrom": 12` يكشف كل كلمة مع نطقها. ونهاية المشهد: `"endAt": "@w20+0.4"` بدل `duration`.
4. الموسيقى تنخفض تلقائيًا أثناء الصوت (ducking) والمخرج −14 LUFS.
