# Arabian Motion Studio — تعليمات العمل (للوكيل وللمطوّر)

مشروع **مستقل** داخل هذا المجلد فقط؛ لا تعدّل ملفات المشاريع الأخرى في المستودع.

## القواعد
1. كل إطار دالة في الزمن فقط: `renderFrame(t)`؛ لا مؤقتات ولا CSS animations ولا عشوائية بلا seed.
2. كل تغيير يُراجَع بـ `sheet` على المدى المتأثر قبل المتابعة (لوحة إطارات بطابع زمني).
3. اتجاه القراءة RTL: التقدّم من اليمين لليسار؛ لا تُحرَّك حروف مفردة (تُكشف الكلمة كاملة).
4. الصور والأيقونات تُسجَّل في `projects/<p>/assets.json`؛ لا يتكرر أصل ولا أيقونة ولا تكوين فني بين المشاهد (`check` يفرض ذلك).
5. مفاتيح API في `.env` فقط؛ لا تُطبع ولا تُكتب في أي ملف أو commit.
6. المقاطع تُصدَّر بإصدارات `_v1, _v2…` ولا يُستبدل إصدار معتمد.
7. مناطق آمنة 9:16: أعلى 220px، أسفل 420px، جانب 60px خالية من النص المهم.

## سير العمل
فكرة/سكربت → (تعليق صوتي mp3 → `sync`) → مشاهد في project.json → `pexels search/pick` → `check` → `sheet` → `render --preview` → `render`.
