# Arabian Motion Studio — تعليمات العمل (للوكيل وللمطوّر)

مشروع **مستقل** داخل هذا المجلد فقط؛ لا تعدّل ملفات المشاريع الأخرى في المستودع.

## القواعد
1. كل إطار دالة في الزمن فقط: `renderFrame(t)`؛ لا مؤقتات ولا CSS animations ولا عشوائية بلا seed.
2. كل تغيير يُراجَع بـ `sheet` على المدى المتأثر قبل المتابعة (لوحة إطارات بطابع زمني).
3. اتجاه القراءة RTL: التقدّم من اليمين لليسار؛ لا تُحرَّك حروف مفردة (تُكشف الكلمة كاملة).
4. الصور والأيقونات تُسجَّل في `projects/<p>/assets.json`؛ لا يتكرر أصل ولا أيقونة ولا تكوين فني بين المشاهد (`check` يفرض ذلك).
5. مفاتيح API في `.env` فقط؛ لا تُطبع ولا تُكتب في أي ملف أو commit.
6. المقاطع تُصدَّر بإصدارات `_v1, _v2…` ولا يُستبدل إصدار معتمد.
7. مناطق آمنة 9:16: أعلى 220px، أسفل 420px، جانب 60px خالية من النص المهم.

## سير العمل
فكرة/سكربت → (تعليق صوتي mp3 → `sync`) → مشاهد في project.json → `pexels search/pick` → `check` → `sheet` → `render --preview` → `render`.

التفاصيل: `README.md` · الخطة: `docs/PLAN.md`.

## الاستوديو (Ms. Memories)
- الواجهة: `npm run studio` ← `studio/server.mjs` + `studio/ui/`. لا تُنشئ محركًا ثانيًا: المعاينة تحمّل `engine/runtime.js` والتصدير يشغّل `src/cli.mjs render`.
- قوالب البراند وباليته في `studio/templates.mjs`؛ ألوان الطبقات بأسماء الباليت (`accent`, `ink`, `bg`, `accent2`, `muted`).
- أي طبقة جديدة في المحرك: أضيفيها في `engine/runtime.js` + حقولها في `layerEditor` (studio/ui/app.js) + قاعدة في `src/validate.mjs` إن لزم.
- لا تدّعي نجاح تكامل لم يُختبر (Pexels/sync غير مختبرين حيًا).

## المخطِّط (المرحلة 2)
- `studio/planner/`: `analyze.mjs` (تحليل الفكرة) ← `copy.mjs` (قصة + نصوص) ← `compose.mjs` (18 تكوينًا + محدِّد التنوع والانتقالات) ← `index.mjs` (`planProject`, `replanScene`, `buildAudio`). `llm.mjs` اختياري ولم يُختبر حيًا.
- كل تكوين يعيد طبقات المحرك الحالية؛ تكوين جديد = دالة في `compose.mjs` + إدراجه في `CANDIDATES` + اسمه يظهر تلقائيًا في الواجهة.
- قواعد ثابتة: لا تكرار تكوين/نص/أيقونة/أصل، النص يُقاس بـ `fit()` قبل وضعه، صور ناقصة = رسم أصلي لا عبارة «صورتك هنا».
- توليد الصور: `studio/imagegen/` سجل مزوّدين بلا مزوّد مفعّل. لا تدّعي أنه يعمل قبل ربط خدمة واختبارها.
- شغّلي `npm test` بعد أي تعديل في المخطِّط.
