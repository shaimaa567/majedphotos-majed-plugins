# خطة التنفيذ — Arabian Motion Studio

## القرار التقني
Chromium بلا واجهة (Playwright) يرسم مشاهد SVG/CSS/DOM كدالة في الزمن `t` ← ffmpeg يرمّز ويمزج الصوت.
السبب: تشكيل عربي صحيح وRTL مجانًا، رسم SVG حاد، سهولة تبديل الصور والأيقونات، وتصدير حتمي.
لا Remotion/Motion Canvas: اعتماديات أثقل وقيود ترخيص، والحاجة هنا تغطيها 400 سطر.

## اختبار المرحلة 1 (ما تحقق فعلًا)
- `check` على الديمو: 0 أخطاء.
- ديمو 4 مشاهد = 14.85 ث، H.264 1080×1920 30fps + AAC، شكل الحروف وترتيب RTL مفحوص بصريًا على لوحات الإطارات.
- اختبار منفصل: صورة بقصّ مضلّع وKen Burns، فيديو بإطارات دقيقة، `@w`/`@scene`/`wordsFrom`، ومزج vo+music(ducking)+sfx بـ loudnorm ← نجح.
- **غير مختبر:** استدعاءات Pexels الحية (لا مفتاح في البيئة) و`sync` (faster-whisper غير مثبّت هنا). الكود مكتوب وفق توثيق الـ API ويحتاج تجربة أولى عندك.

# استوديو Ms. Memories (توسعة فوق المحرك نفسه)

**البنية:** `studio/server.mjs` (Node بلا اعتماديات) يخدم الواجهة `studio/ui/`، ويحمّل `engine/runtime.js` نفسه داخل iframe للمعاينة، ويشغّل `src/cli.mjs render` نفسه للتصدير. لا محرك ثانٍ ولا واجهة شكلية؛ المعاينة والتصدير يشتركان في الكود.

| المرحلة | المحتوى | الحالة |
|---|---|---|
| 1 | واجهة استوديو + مشاريع + معاينة حية + تعديل بصري + رفع صور + حفظ + تصدير + عناصر الهوية + 3 قوالب | ✅ منجزة ومختبرة بمتصفح آلي |
| 2 | توليد المشاهد تلقائيًا من وصف الفكرة (قابلة للتعديل) | مخطط |
| 3 | مكتبة وسائط: Pexels (بحث/اختيار من الواجهة) + أيقونات + صوت/تعليق صوتي + `sync` من الواجهة | مخطط |
| 4 | محرر التصاميم الثابتة (منشور/تصميم) وتصدير PNG بمقاسات متعددة | مخطط |

## اختبار المرحلة 1 (فعلي، بمتصفح Chromium آلي)
إنشاء مشروع ← 4 مشاهد تتحمل ← تعديل نص (يتحدث في المعاينة) ← رفع صورة وربطها بـ Polaroid ← سحب العنصر (الإحداثي يتغير) ← تبديل السمة ← تراجع ← حفظ تلقائي ← تصدير MP4 من الواجهة (H.264+AAC) — بلا أخطاء في الـ console.
**ما لم يُختبر:** Pexels الحي، `sync`/faster-whisper، الصوت من الواجهة، المتصفحات غير Chromium، التصدير المتزامن من أكثر من نافذة.
